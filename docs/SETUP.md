# 준비물과 업데이트

## 준비물

- 윈도우 PC
- 한컴오피스 한글 (2022에서 확인했습니다)
- 구글 안티그래비티
- 인터넷 연결 (설치할 때 필요한 프로그램을 내려받습니다. 10분쯤 걸립니다)
- 교재 PDF (스캔본도 됩니다)

한글 프로그램과 AI 서비스 이용권은 포함되어 있지 않습니다. 맥과 리눅스에서는 한글 파일을 만들 수 없습니다.

## 설치

[README의 설치 문장](../README.md#설치)을 안티그래비티에 붙여 넣으면 에이전트가 설치합니다. 에이전트가 따르는 순서는 [AGENT_INSTALL.md](../AGENT_INSTALL.md)에 있습니다.

## 업데이트

안티그래비티에 이렇게 말합니다.

```text
설치된 hwp-problem-picker 스킬을 https://github.com/acb0808/hwp-problem-picker 의 최신 버전으로 업데이트해 주세요.
저장소의 AGENT_INSTALL.md에서 "업데이트" 부분을 읽고 그대로 진행해 주세요.
```

끝나면 안티그래비티를 껐다 다시 켭니다.

## 양식 바꾸기

문서는 스킬에 든 기본 양식(쪽마다 큰 칸 넷)으로 만들어집니다. 작업 폴더에 `양식.hwp`라는 파일을 두면 그 파일을 대신 씁니다. 다만 지금은 기본 양식과 같은 구조(머리말 표, 첫 쪽 표, 둘째 쪽 표)여야 합니다.

설정을 바꾸고 싶으면 에이전트에게 말로 시키면 됩니다. 예: "hwp-problem-picker 설정에서 같은 문제를 읽히는 횟수를 3번으로 줄여 줘."
