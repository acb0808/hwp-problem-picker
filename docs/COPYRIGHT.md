# 저작권 안내

교재의 저작권은 출판사와 저자에게 있습니다. 이 스킬은 사용자가 정당하게 가진 자료를 수업 준비에 쓰기 편하게 옮기는 도구입니다. 만든 문서를 배포하거나 판매할 때는 해당 교재의 이용 조건을 직접 확인하세요.

이 저장소에는 교재나 그 내용이 들어 있지 않습니다.

## AI 서비스로 보내지는 자료

교재의 쪽 그림은 문제를 읽기 위해 사용 중인 AI 서비스로 보내집니다. 자료를 넘기기 전에 그 서비스의 데이터 취급 조건을 확인하세요.
